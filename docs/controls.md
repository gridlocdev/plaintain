# Controls

Shortcuts are shown for macOS. On Linux, use Ctrl where this page says ⌘.

|                                    | Keyboard          |
| ---------------------------------- | ----------------- |
| New / Open                         | `⌘N` / `⌘O`       |
| Save / Save As                     | `⌘S` / `⇧⌘S`      |
| Preferences                        | `⌘,`              |
| Undo / Redo                        | `⌘Z` / `⇧⌘Z`      |
| Cut / Copy / Paste                 | `⌘X` / `⌘C` / `⌘V` |
| Select All                         | `⌘A`              |
| Add next occurrence                | `⌘D`              |
| Move line up / down                | `⌥↑` / `⌥↓`       |
| Copy line up / down                | `⇧⌥↑` / `⇧⌥↓`     |
| Indent / outdent selected lines    | `Tab` / `⇧Tab`    |
| Find                               | `⌘F`              |
| Find and Replace                   | `⌥⌘F`             |
| Replace one / all (in replace box) | `Enter` / `⌘Enter` |
| Go to Line                         | `⌘G`              |
| Word Wrap                          | `⌥⌘R`             |
| Line Numbers                       | `⌥⌘L`             |
| Show Invisibles                    | `⌥⌘I`             |
| Zoom in / out / reset              | `⌘+` / `⌘−` / `⌥⌘0` |

Moving the caret works as in other Mac editors: ⌥←/⌥→ move by word, ⌥Backspace deletes a word, and ⌘↑/⌘↓ go to the start or end of the document. Home goes to the first non-blank character of the line, then to the line's true start. In the text, Escape removes the extra selections first, then shrinks the selection to a caret. In the find strip, Escape closes it.
